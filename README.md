# KLH-BACHUPALLY_DDCA_Y26_S4_SR-latch-JK-D-T-flip-flop-and-diff-b/w-level-and-edge-triggering
Design an SR latch, D flip-flop, JK flip-flop and T flip-flop, and explain the difference between level-triggered and edge-triggered operation.
Software Used : LOGISIM 2.7.1

Project Description

This project focuses on designing and understanding four fundamental sequential logic circuits used in digital electronics: SR Latch, D Flip-Flop, JK Flip-Flop, and T Flip-Flop. These circuits are essential building blocks in digital systems because they store binary information and control the flow of data based on input signals and timing conditions.

The project explains the working principles, truth tables, and behavior of each circuit, along with the differences between level-triggered and edge-triggered operation.

Objectives

Design and understand the working of an SR latch.

Implement a D flip-flop for storing a single bit of data.

Design a JK flip-flop with set, reset, hold, and toggle operations.

Implement a T flip-flop for toggling the output state.

Study the truth tables and output behavior of each circuit.

Understand the difference between level-triggered and edge-triggered circuits.

Types of Circuits

SR Latch: Stores one bit of information using Set and Reset inputs. It is a level-sensitive storage element.

D Flip-Flop: Stores the value of the D input at the active clock edge.

JK Flip-Flop: An improved version of the SR flip-flop that supports toggling when both inputs are HIGH.

T Flip-Flop: Toggles its output when the T input is HIGH at the active clock edge and holds its state when the input is LOW.

Level-Triggered vs Edge-Triggered Operation

Level-triggered operation: The circuit responds to its control or enable signal while it remains at a specified logic level, either HIGH or LOW. An SR latch is a common example.

Edge-triggered operation: The circuit responds only when the clock changes state, either from LOW to HIGH (positive edge) or from HIGH to LOW (negative edge). D, JK, and T flip-flops are common examples.
